# Prompt blocks — schema v0.1

Дата: 2026-09-28. Совместимый контракт текущего формата. Файл: `schemas/prompt-blocks.v0.1.schema.json` (JSON Schema Draft 2020-12).

Документ фиксирует формат, а не объявляет библиотеку проверенной на генерации. Runtime пока не подключает JSON Schema. Данные, defaults, тексты и код не мигрировались.

## Версии

`v0.1` — версия спецификации. Уже существующее `schema_version: 1` — числовой идентификатор wire format; он сохраняется. `version: 1` внутри блока — ревизия конкретного блока. Изменение текста, параметров, смысла или конфликтов требует увеличения version. ID остаётся стабильным; его нельзя переиспользовать для другого смысла.

## Контракт

| Поле | Тип | Правило |
|---|---|---|
| schema_version | integer | Ровно 1 |
| sections | array | Ровно девять текущих секций, в зафиксированном порядке |
| blocks | array | Непустой список; ID уникальны во всей библиотеке |
| blocks[].id | string | Стабильный ID: `^[a-z][a-z0-9_-]*$` |
| en / ru | string | Непустые названия EN/RU, не полные переводы prompt |
| category | enum | Одна из 10 исходных категорий |
| section | enum | Одна из девяти секций |
| text | string | Непустой английский технический шаблон |
| parameters | object | Именованные строковые defaults; пустой объект допустим |
| status | const | Только GENERATED для текущей библиотеки |
| version | integer | Положительная ревизия блока |
| conflicts | array | Уникальные ID несовместимых блоков; пустой массив допустим |

Неизвестные поля корня и блока запрещены. Параметры — непустые строки до 2000 символов; имена `^[a-z][a-z0-9_]*$`. Синтаксис подстановки: `{{parameter_name}}`. Типизация roughness, единицы масштаба и диапазоны значений пока не определены: не выдавать строки за числовые PBR-параметры.

## Межобъектные инварианты (дополнительно к JSON Schema)

1. Уникальные block ID; все ссылки dictionary.block_id, presets.blocks и conflicts разрешаются.
2. Конфликт не ссылается на самого себя. Для совместимости с текущим Composer пары конфликтов симметричны. При нарушении — FAIL; не пропускать конфликт молча.
3. Набор имён placeholders точно равен набору ключей parameters. Повторное использование placeholder допустимо. Неизвестные или незакрытые placeholders — FAIL.
4. Названия и категории dictionary совпадают с соответствующими полями блока. Это временное правило против расхождения дублированных метаданных.
5. Секции выводятся в порядке sections; внутри секции текущий алгоритм сохраняет порядок выбора. Нельзя обещать одинаковый текст для разных порядков выбора.
6. Один block ID — одна конфигурация в комбинации. Повторная добавка сохраняет текущие параметры; альтернативные значения требуют явного решения, а не молчаливого overwrite.

## Статусы и доказательства

GENERATED означает авторский стартовый текст. VALIDATED для кода/JSON и TESTED для Composer относятся к программным проверкам, не повышают status блоков.

Переход блоков в VALIDATED / TESTED / Production Standard пока закрыт: отсутствует модель доказательств. Следующая согласованная ревизия должна определить provenance, критерии экспертной проверки, test IDs, модель/версию, workflow hash, input/mask/reference, seed и настройки, результат и принятие пользователем. Production Standard возможен только после реальных тестов и отдельного принятия. Текущая schema намеренно отклоняет любые статусы кроме GENERATED.

## Связанные форматы: зафиксированы описательно, отдельные схемы ещё не созданы

- dictionary.json: массив `{id, term_en, term_ru, category, description_ru, block_id}`. Это стартовый каталог 1:1, не полноценная терминологическая база.
- presets.json: массив `{id, name, blocks: [block_id]}`. Параметры и версии блоков не фиксируются.
- Экспорт комбинации: `{schema_version: 1, name, blocks: [{id, parameters}]}`. Это отдельный формат, его нельзя валидировать схемой библиотеки.
- localStorage: массив `{name, blocks}` под ключом `archviz-prompt-studio-v1`; без schema version и library revision. Сохранения НЕ обеспечивают воспроизводимость после изменения библиотеки.

## Предлагаемая следующая ревизия — НЕ внедрена

| Сейчас | Предложение | Причина / риск миграции |
|---|---|---|
| Нет scope и prerequisites | edit_scope, required_inputs, requires / requires_any | Материал нельзя применять без области; глобальные и локальные проходы нельзя смешивать молча |
| Строковые defaults | Объекты параметров с type, label_ru, default, constraints, unit | Изменится чтение parameters в UI и Composer |
| Статус без доказательств | provenance + verification records | Нужен отдельный протокол prompt tests |
| Пресеты хранят только ID | Ссылки ID + version + параметры + library revision | Старые сборки требуют явного разрешения несовпадения версий |
| EN-only template | Полный RU template/перевод по согласованной модели | Название RU не является переводом инструкции |

Сначала согласовать необходимые поля на конкретных сценариях Facade / Final Polish / People, затем миграция с резервной копией, затем Composer.
